Default parameter evaluation

The rule: a default is evaluated once, when def runs, and every call that omits the argument reuses that one object.

Defaults · predict the output

A list as a default

def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags

print(add_tag("urgent"))
print(add_tag("billing"))
print(add_tag("vip", []))
print(add_tag("late"))
Output and why — say yours first

Python 3.14.7 prints

['urgent']
['urgent', 'billing']
['vip']
['urgent', 'billing', 'late']

A default is evaluated once, when the def statement runs, and stored on the function in add_tag.__defaults__. Every call that omits tags gets that same list object, so the appends pile up. Passing a list explicitly bypasses the shared one, which is why the "vip" call looks correct and hides the bug.

The fix

def add_tag(tag, tags=None):
    if tags is None:
        tags = []
    tags.append(tag)
    return tags

print(add_tag("urgent"))
print(add_tag("billing"))

Which prints

['urgent']
['billing']

A generated id as a default

import itertools

ids = itertools.count(1)

def new_ticket(title, ticket_id=next(ids)):
    return ticket_id, title

print(new_ticket("login fails"))
print(new_ticket("card declined"))
Output and why — say yours first

Python 3.14.7 prints

(1, 'login fails')
(1, 'card declined')

next(ids) ran exactly once, when the function was defined. The same trap freezes datetime.now(), time.time() and uuid4() in a default: every record gets the moment the module was imported. Anything that must be fresh per call belongs in the body.

The fix

import itertools

ids = itertools.count(1)

def new_ticket(title, ticket_id=None):
    if ticket_id is None:
        ticket_id = next(ids)
    return ticket_id, title

print(new_ticket("login fails"))
print(new_ticket("card declined"))

Which prints

(1, 'login fails')
(2, 'card declined')

Late binding, and the default-argument trick

handlers = [lambda: n for n in range(3)]
print([h() for h in handlers])

handlers = [lambda n=n: n for n in range(3)]

What dataclasses do about it

from dataclasses import dataclass

@dataclass
class Team:
    name: str
    members: list = []
Output and why — say yours first

Python 3.14.7 prints

Traceback (most recent call last): …
ValueError: mutable default <class 'list'> for field members is not allowed: use default_factory

dataclasses refuse the trap when the class is defined, because a list default would be shared by every instance. Since Python 3.11 the check rejects any unhashable default, not only list, dict and set. field(default_factory=list) calls list() once per instance.

The fix

from dataclasses import dataclass, field

@dataclass
class Team:
    name: str
    members: list = field(default_factory=list)

print(Team("risk").members is Team("payments").members)

Which prints

False

Object identity versus value equality

The rule: == asks whether values are equal and runs code the class controls; is asks whether two names are the same object and cannot be overridden.

Identity · predict the output

Equal, identical, aliased

a = [1, 2, 3]
b = [1, 2, 3]
c = a
print(a == b, a is b, a is c)
c.append(4)
print(a, b)
Output and why — say yours first

Python 3.14.7 prints

True False True
[1, 2, 3, 4] [1, 2, 3]

== asks whether the values are equal. is asks whether both names refer to the same object. c = a copies the reference, not the list, so appending through c changes a. b is a separate list that happens to hold equal values.

Identity · predict the output

Integers that are sometimes identical

x, y = int("256"), int("256")
print(x == y, x is y)
x, y = int("257"), int("257")
print(x == y, x is y)
Output and why — say yours first

Python 3.14.7 prints

True True
True False

CPython pre-creates the integers from −5 to 256 and hands out the same objects, so is happens to be True up to 256 and False one step later. That is an implementation detail. Literals in one file can even be merged into a single constant, which is why this example builds the numbers at run time. The rule is simple: never use is to compare numbers or strings.

A class with no __eq__

class Trade:
    def __init__(self, symbol, qty):
        self.symbol, self.qty = symbol, qty

print(Trade("C", 100) == Trade("C", 100))
print(Trade("C", 100) in [Trade("C", 100)])
Output and why — say yours first

Python 3.14.7 prints

False
False

Without __eq__ a class inherits object.__eq__, which is identity. List membership uses == per element, so it fails too, and so do list.remove, list.index and list.count. A frozen dataclass generates __eq__ and a matching __hash__ from the fields.

The fix

from dataclasses import dataclass

@dataclass(frozen=True)
class Trade:
    symbol: str
    qty: int

print(Trade("C", 100) == Trade("C", 100))
print(len({Trade("C", 100), Trade("C", 100)}))

Which prints

True
1

__eq__ without __hash__

class Customer:
    def __init__(self, cid):
        self.cid = cid

    def __eq__(self, other):
        return isinstance(other, Customer) and self.cid == other.cid

print(Customer(7) == Customer(7))
print(Customer.__hash__)
print(len({Customer(7), Customer(7)}))
Output and why — say yours first

Python 3.14.7 prints

True
None
Traceback (most recent call last): …
TypeError: cannot use 'Customer' as a set element (unhashable type: 'Customer')

Python 3.12.3 prints this instead

True
None
Traceback (most recent call last): …
TypeError: unhashable type: 'Customer'

Defining __eq__ without __hash__ sets __hash__ to None, so instances can no longer go in a set or be dict keys. The contract: objects that compare equal must hash equal, and a hash must not change while the object sits in a set. So hash exactly the immutable fields that __eq__ compares. Older Pythons word the error as unhashable type: 'Customer'.

The fix

class Customer:
    def __init__(self, cid):
        self.cid = cid

    def __eq__(self, other):
        return isinstance(other, Customer) and self.cid == other.cid

    def __hash__(self):
        return hash(self.cid)

print(len({Customer(7), Customer(7)}))

Which prints

1

[[1, 0, 0], [1, 0, 0], [1, 0, 0]]

A lazy generator outliving its with block

from pathlib import Path

Path("trades.txt").write_text("C,100\nJPM,50\n", encoding="utf-8")

with open("trades.txt", encoding="utf-8") as f:
    rows = (line.rstrip("\n").split(",") for line in f)
print(list(rows))
Output and why — say yours first

Python 3.14.7 prints

Traceback (most recent call last): …
ValueError: I/O operation on closed file.

The generator expression is lazy: no line is read until list() pulls from it, and by then the with block has closed the file. Either consume the data inside the block, or move the with into a generator function so the file stays open exactly as long as someone is iterating.

The fix

from pathlib import Path

Path("trades.txt").write_text("C,100\nJPM,50\n", encoding="utf-8")

def read_rows(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.rstrip("\n").split(",")

print(list(read_rows("trades.txt")))

Which prints

[['C', '100'], ['JPM', '50']]

Removing while iterating

amounts = [120, -40, -15, 60, -5]

Removing an item shifts everything after it one place left, while the loop's hidden index keeps moving forward. So the element right after each removal is never examined, and −15 survives. Build a new list instead.

Spoken questions

Answer these out loud before opening them

The last two go beyond the email's topics. They cover the asyncio and FastAPI work the Citi posting names, and are cheap insurance for later rounds.

Why does Python evaluate a default only once, and when is that useful?
  • def is an executable statement that builds a function object. Default expressions are evaluated at that moment and stored in __defaults__ and __kwdefaults__.
  • It is cheap, since nothing is re-evaluated per call, and it is predictable: the default is whatever existed at definition time.
  • Deliberate uses: a memo dict such as def fib(n, _memo={}), or freezing a loop variable with lambda n=n: n. functools.lru_cache and functools.partial express both more clearly, so say that too.
The standard fix uses None. What if None is a valid argument?
  • Use a private sentinel: _MISSING = object(), then def f(x=_MISSING) and if x is _MISSING:.
  • A fresh object() is identical only to itself, so no caller value can collide with it. This is one of the legitimate uses of is.
  • Making the parameter keyword-only with * also keeps call sites explicit.
When is is the right comparison?
  • Singletons: None, and True/False when you must distinguish them from 1 and 0.
  • Sentinel objects, and enum members, where is and == agree.
  • Asking whether two names alias the same mutable object, for example to avoid copying onto itself or to detect a cycle.
  • Never for numbers, strings or tuples: their identity is an interpreter detail that changes with how the value was produced.
What is the contract between __eq__ and __hash__, and how do dataclasses handle it?
  • If a == b then hash(a) == hash(b). The hash must also stay stable while the object is in a set or used as a dict key.
  • Defining __eq__ sets __hash__ to None, so the class becomes unhashable until you add one. Hash exactly the immutable fields __eq__ compares.
  • @dataclass has eq=True by default, which leaves instances unhashable. frozen=True generates a field-based hash. unsafe_hash=True forces one on a mutable class, and mutating a hashed field then makes the object unfindable in its set.
A function changed the list its caller passed in. Explain what happened.
  • Python passes references to objects, sometimes called call by sharing. Rebinding the parameter name inside the function does not affect the caller. Mutating the object does, because both names refer to it.
  • Defend at the boundary: copy on the way in with list(x) or dict(x), copy.deepcopy for nesting, or return new objects instead of mutating.
  • Tuples and frozen dataclasses make data that should not change impossible to change.
How would you total amounts per account from a 50 GB CSV on a laptop?
  • Stream it: with open(path, newline="", encoding="utf-8") as f, then for row in csv.DictReader(f), accumulating into a dict keyed by account.
  • Memory is then proportional to the number of distinct accounts, not the size of the file. Parse types once per row, and collect malformed rows with their line numbers instead of crashing on row 400 million.
  • If even the distinct keys do not fit: partition rows into files by a hash of the key and aggregate each file, or sort externally. Parallelise over byte ranges if the parsing is CPU-bound.
  • Then mention the tools you would really reach for at scale, such as chunked pandas or a SQL engine, after showing you can write the streaming version.
What does with guarantee, and how do you write your own context manager?
  • with calls __enter__, and always calls __exit__ on the way out: normal exit, exception, return or break. Files close and locks release deterministically.
  • If __exit__ returns True, the exception is suppressed, which is rarely what you want.
  • Write one as a class with those two methods, or with @contextlib.contextmanager and a try/finally around a single yield. For a variable number of resources, use contextlib.ExitStack.
Why pass encoding=, and why newline="" for CSV files?
  • Without encoding, text mode uses the platform's locale encoding, such as cp1252 on many Windows machines. Code that works on a laptop then fails on a server. PEP 686 makes UTF-8 mode the default in Python 3.15, but explicit is still correct.
  • The csv documentation requires newline="", so that the csv module, not the file layer, handles \r\n endings and newlines inside quoted fields.
  • Use binary mode ("rb") for data that is not text, and no encoding at all there.
How do you write a file so that a crash cannot leave it half-written?
  • Write to a temporary file in the same directory, flush() and os.fsync() it, then os.replace(tmp, final).
  • The rename is atomic on POSIX and Windows, so readers see the old file or the new one, never a partial one.
  • Same directory matters: a rename across filesystems is a copy, which is not atomic.
List, iterator, generator: what is the difference, and when do you pick each?
  • A list holds every item: reusable, indexable, has a length, costs O(n) memory.
  • An iterator yields items one at a time through __next__ and remembers its position; it is single-pass.
  • A generator, from a function with yield or a generator expression, is a lazy iterator: O(1) memory, ideal for pipelines over large input and for early exit with any, next or itertools.islice.
  • Pick a list when you need several passes, random access or len; pick a generator when you stream.
Quote the costs of the operations you will lean on in the coding round.
  • List: append O(1) amortised; x in list O(n); pop(0) and insert(0, x) O(n), so use collections.deque for queues.
  • Dict and set: get, set and in are O(1) on average.
  • sorted is O(n log n) and stable. heapq.nsmallest(k, xs) is about O(n log k). min, max, sum and Counter(xs) are O(n).
  • String += in a loop can go quadratic, so collect parts and "".join them. Slicing copies, O(k).
Sort by count descending, then name ascending. And what if both keys are strings?
  • With a numeric primary key, negate it: sorted(rows, key=lambda r: (-r.count, r.name)).
  • A string cannot be negated. Use stability instead: sort by the secondary key first, then by the primary key with reverse=True. Equal primary keys keep their secondary order.
  • For the single best item, min with the same key is O(n) instead of O(n log n).
Why not float for money, and what would you use at a bank?
  • Binary floats cannot represent most decimal fractions: 0.1 + 0.2 != 0.3, and the errors accumulate in totals.
  • Use decimal.Decimal built from strings, Decimal("0.10"), never Decimal(0.1), with explicit rounding through quantize. Or store integer minor units such as cents.
  • If an exercise hands you floats, follow the spec, and say this out loud: it is a cheap signal that you think like someone who would handle ledgers.
What happens if you call a blocking function inside async def?
  • It blocks the event loop. Every other coroutine on that loop, including every other request a FastAPI worker is serving, stalls until the call returns.
  • Use the async equivalent, such as await asyncio.sleep or an async HTTP client. For unavoidable blocking or CPU-bound work, use await asyncio.to_thread(fn, ...) or a process pool.
  • In FastAPI, a plain def endpoint runs in a threadpool, so blocking code there does not freeze the loop. async def is only faster when everything awaited is truly non-blocking.
Call three LLM tools concurrently with a deadline, and tolerate one failing.
  • asyncio.gather(*calls, return_exceptions=True) returns every result or exception, so one failure does not discard the others. Wrap it in asyncio.timeout(...) (Python 3.11+) or asyncio.wait_for.
  • asyncio.TaskGroup (3.11+) cancels the siblings when one task fails. Choose it when a partial answer is worthless.
  • Bound fan-out with an asyncio.Semaphore, and retry 429 and 5xx responses with exponential backoff plus jitter, under an overall budget.

“record runs millions of times a day and top_customers every second. What changes?” Move work to the write path: update per-customer volume, per-category sum and count, and per-hour counts inside record, so reads cost O(groups) or O(c log k). “Two threads call record on the same account.” The balance check and the update are a check-then-act race. Lock per account, or push it into the database as one conditional statement, such as an UPDATE that only applies when the new balance stays at or above zero, and check the affected-row count.

“Write branch_summary in SQL.”

SELECT c.branch,
       COUNT(DISTINCT c.customer_id) AS customers,
       COUNT(a.account_id)           AS accounts,
       COALESCE(SUM(a.balance), 0)   AS total_balance
FROM customers c
LEFT JOIN accounts a ON a.customer_id = c.customer_id
GROUP BY c.branch;

The LEFT JOIN keeps customers without accounts; COUNT(a.account_id) ignores the resulting nulls.

class Bank:
    """Problem 1 — customers own accounts; accounts carry transactions.

    Timestamps are "YYYY-MM-DD HH:MM" strings. Amounts are whole dollars:
    positive is a credit, negative is a debit. Unknown ids raise ValueError.
    """

    def __init__(self):
        self.customers = {}                    # customer_id -> (name, branch)
        self.account_owner = {}                # account_id -> customer_id
        self.accounts_of = defaultdict(list)   # customer_id -> [account_id, ...]
        self.balances = {}                     # account_id -> running balance, O(1) reads
        self.transactions = []                 # (account_id, amount, timestamp, category)

    # ---- Part 1 ------------------------------------------------------------
    def add_customer(self, customer_id, name, branch):
        """Register a customer. A repeated customer_id raises ValueError."""
        if customer_id in self.customers:
            raise ValueError(f"customer {customer_id} already exists")
        self.customers[customer_id] = (name, branch)

    def open_account(self, account_id, customer_id):
        """Open an account for an existing customer. Unknown customer or repeated account_id raises ValueError."""
        if customer_id not in self.customers:
            raise ValueError(f"unknown customer {customer_id}")
        if account_id in self.account_owner:
            raise ValueError(f"account {account_id} already exists")
        self.account_owner[account_id] = customer_id
        self.accounts_of[customer_id].append(account_id)
        self.balances[account_id] = 0

    def record(self, account_id, amount, timestamp, category):
        """Apply one transaction. An unknown account, or a debit that would take the balance
        below zero, raises ValueError and records nothing. Exactly zero is allowed."""
        if account_id not in self.balances:
            raise ValueError(f"unknown account {account_id}")
        if self.balances[account_id] + amount < 0:
            raise ValueError("insufficient funds")
        self.balances[account_id] += amount
        self.transactions.append((account_id, amount, timestamp, category))

    def balance(self, account_id):
        """Current balance of one account."""
        if account_id not in self.balances:
            raise ValueError(f"unknown account {account_id}")
        return self.balances[account_id]

    # ---- Part 2 ------------------------------------------------------------
    def customer_balance(self, customer_id):
        """Sum of balances across every account the customer owns; 0 if they own none."""
        if customer_id not in self.customers:
            raise ValueError(f"unknown customer {customer_id}")
        # .get, not [] — indexing a defaultdict would insert an empty entry as a side effect
        return sum(self.balances[a] for a in self.accounts_of.get(customer_id, []))

    def branch_summary(self):
        """{branch: {"customers": int, "accounts": int, "total_balance": int}} for every branch with a customer."""
        summary = {}
        for customer_id, (_, branch) in self.customers.items():
            row = summary.setdefault(branch, {"customers": 0, "accounts": 0, "total_balance": 0})
            row["customers"] += 1
            row["accounts"] += len(self.accounts_of.get(customer_id, []))
            row["total_balance"] += self.customer_balance(customer_id)
        return summary

    # ---- Part 3 ------------------------------------------------------------
    def average_amount_by_category(self):
        """{category: mean of abs(amount), rounded to 2 decimals} over recorded transactions."""
        totals = defaultdict(int)
        counts = Counter()
        for _, amount, _, category in self.transactions:
            totals[category] += abs(amount)
            counts[category] += 1
        return {category: round(totals[category] / counts[category], 2) for category in counts}

    def busiest_hour(self):
        """Hour of day (0-23) with the most transactions. Ties go to the earliest hour. None if there are none."""
        counts = Counter(int(timestamp[11:13]) for _, _, timestamp, _ in self.transactions)
        if not counts:
            return None
        return min(counts, key=lambda hour: (-counts[hour], hour))

    # ---- Part 4 ------------------------------------------------------------
    def top_customers(self, k):
        """Names of the k customers who moved the most money (sum of abs(amount)), highest first.
        Ties go to the name that sorts first. Customers with no transactions still rank, at 0."""
        volume = defaultdict(int)
        for account_id, amount, _, _ in self.transactions:
            volume[self.account_owner[account_id]] += abs(amount)
        # nsmallest on a (-volume, name) key: O(c log k) instead of sorting all c customers
        best = heapq.nsmallest(k, self.customers, key=lambda c: (-volume.get(c, 0), self.customers[c][0]))
        return [self.customers[c][0] for c in best]

    def most_common_category(self, customer_id):
        """The category this customer uses most often across all their accounts.
        Ties go to the category that sorts first. None if they have no transactions."""
        if customer_id not in self.customers:
            raise ValueError(f"unknown customer {customer_id}")
        mine = set(self.accounts_of.get(customer_id, []))
        counts = Counter(category for account_id, _, _, category in self.transactions if account_id in mine)
        if not counts:
            return None
        return min(counts, key=lambda category: (-counts[category], category))

class ProjectTracker:
    """Problem 2 — employees log hours against projects. Dates are "YYYY-MM-DD".

    Unknown ids raise ValueError.
    """

    def __init__(self):
        self.employees = {}                          # emp_id -> (name, department)
        self.projects = {}                           # project_id -> name
        self.total_by_employee = defaultdict(float)  # emp_id -> hours
        self.day_total = defaultdict(float)          # (emp_id, date) -> hours, for the 24-hour rule
        self.date_total = defaultdict(float)         # date -> hours across everyone
        self.hours_on = defaultdict(dict)            # project_id -> {emp_id: hours}
        self.projects_of = defaultdict(set)          # emp_id -> {project_id}

    # ---- Part 1 ------------------------------------------------------------
    def add_employee(self, emp_id, name, department):
        """Register an employee. A repeated emp_id raises ValueError."""
        if emp_id in self.employees:
            raise ValueError(f"employee {emp_id} already exists")
        self.employees[emp_id] = (name, department)

    def add_project(self, project_id, name):
        """Register a project. A repeated project_id raises ValueError."""
        if project_id in self.projects:
            raise ValueError(f"project {project_id} already exists")
        self.projects[project_id] = name

    def log(self, emp_id, project_id, date, hours):
        """Log hours. Unknown ids, hours <= 0, or pushing that employee's total for that date
        above 24 raises ValueError and logs nothing. Exactly 24 is allowed."""
        if emp_id not in self.employees or project_id not in self.projects:
            raise ValueError("unknown employee or project")
        if hours <= 0:
            raise ValueError("hours must be positive")
        if self.day_total.get((emp_id, date), 0) + hours > 24:
            raise ValueError("more than 24 hours in one day")
        self.day_total[(emp_id, date)] += hours
        self.total_by_employee[emp_id] += hours
        self.date_total[date] += hours
        self.hours_on[project_id][emp_id] = self.hours_on[project_id].get(emp_id, 0) + hours
        self.projects_of[emp_id].add(project_id)

    def total_hours(self, emp_id):
        """Total hours this employee has logged; 0 if none."""
        if emp_id not in self.employees:
            raise ValueError(f"unknown employee {emp_id}")
        return self.total_by_employee.get(emp_id, 0)

    # ---- Part 2 ------------------------------------------------------------
    def department_hours(self):
        """{department: total hours} for every department that has an employee (0 included)."""
        totals = {}
        for emp_id, (_, department) in self.employees.items():
            totals[department] = totals.get(department, 0) + self.total_by_employee.get(emp_id, 0)
        return totals

    def project_average(self, project_id):
        """Average hours per contributing employee (total / distinct employees), rounded to 2 decimals.
        0.0 if nobody has logged on it."""
        if project_id not in self.projects:
            raise ValueError(f"unknown project {project_id}")
        team = self.hours_on.get(project_id, {})
        if not team:
            return 0.0
        return round(sum(team.values()) / len(team), 2)

    # ---- Part 3 ------------------------------------------------------------
    def busiest_date(self):
        """Date with the most hours logged across everyone. Ties go to the earliest date. None if empty."""
        if not self.date_total:
            return None
        # ISO dates sort chronologically as strings, so the date itself is a valid tie-break key
        return min(self.date_total, key=lambda date: (-self.date_total[date], date))

    def top_contributor(self, project_id):
        """Name of the employee with the most hours on this project. Ties by name A-Z. None if nobody."""
        if project_id not in self.projects:
            raise ValueError(f"unknown project {project_id}")
        team = self.hours_on.get(project_id, {})
        if not team:
            return None
        best = min(team, key=lambda emp_id: (-team[emp_id], self.employees[emp_id][0]))
        return self.employees[best][0]

    # ---- Part 4 ------------------------------------------------------------
    def collaborators(self, emp_id):
        """Names of the other employees who share at least one project with emp_id, ordered by
        number of shared projects (most first), then name A-Z."""
        if emp_id not in self.employees:
            raise ValueError(f"unknown employee {emp_id}")
        shared = Counter()
        for project_id in self.projects_of.get(emp_id, ()):
            for other in self.hours_on[project_id]:
                if other != emp_id:
                    shared[other] += 1
        ranked = sorted(shared, key=lambda other: (-shared[other], self.employees[other][0]))
        return [self.employees[other][0] for other in ranked]

def _minutes(clock):
    """ "9:05" -> 545. Parse once into a number; never compare clock strings."""
    hours, minutes = clock.split(":")
    return int(hours) * 60 + int(minutes)


class Order:
    def __init__(self, order_id, customer, amount, placed_at):
        self.order_id = order_id
        self.customer = customer
        self.amount = amount
        self.placed_at = placed_at  # "H:MM" or "HH:MM", 24-hour clock

    def __eq__(self, other):
        if not isinstance(other, Order):
            return NotImplemented
        return self.order_id == other.order_id

    def __hash__(self):
        # FIX 2 — defining __eq__ sets __hash__ to None. Hash exactly the field(s) __eq__ compares.
        return hash(self.order_id)


class OrderBook:
    """In-memory book of customer orders. A feed can resend an order, so order_id is identity."""

    def __init__(self, orders=None):
        # FIX 1 — a [] default is built once, when `def` runs, and shared by every OrderBook().
        # Copy a caller's list too, so their later mutations cannot reach into this book.
        self.orders = list(orders) if orders is not None else []

    def add(self, order):
        self.orders.append(order)

    def unique_orders(self):
        """A list of the orders with repeated order_ids removed: first occurrence kept, original order preserved."""
        # FIX 2 — a set loses order and needs __hash__; dict keys keep the FIRST equal key and insertion order.
        return list(dict.fromkeys(self.orders))

    def orders_for(self, customer):
        """Every order placed by this customer name."""
        # FIX 3 — `is` asks "same object?"; a name read from a file or request is an equal but different object.
        return [o for o in self.orders if o.customer == customer]

    def orders_between(self, start, end):
        """Orders placed at or after start and before end, e.g. orders_between("9:00", "12:00")."""
        # FIX 4 — as strings, "9:30" < "12:00" is False because "9" > "1".
        low, high = _minutes(start), _minutes(end)
        return [o for o in self.orders if low <= _minutes(o.placed_at) < high]

    def average_amount(self):
        """Mean order amount; 0.0 for an empty book."""
        if not self.orders:  # FIX 5 — ZeroDivisionError on an empty book
            return 0.0
        return sum(o.amount for o in self.orders) / len(self.orders)

    def top_customer(self):
        """Customer name with the highest total spend; ties go to the name that sorts first; None if empty."""
        # FIX 6 — crashed on an empty book (best[1] on None), and re-summed every order per order: O(n^2).
        totals = defaultdict(float)
        for o in self.orders:
            totals[o.customer] += o.amount
        if not totals:
            return None
        return min(totals, key=lambda customer: (-totals[customer], customer))

    def busiest_hour(self):
        """Part 2 (new method): hour 0-23 with the most orders; ties go to the earliest hour; None if empty."""
        counts = Counter(_minutes(o.placed_at) // 60 for o in self.orders)
        if not counts:
            return None
        return min(counts, key=lambda hour: (-counts[hour], hour))

    @classmethod
    def load(cls, path):
        """Build a book from a CSV file whose header is order_id,amount,placed_at,customer."""
        # FIX 7 — header row parsed as data, trailing "\n" left on the last column, file never closed,
        # platform-default encoding. csv.DictReader + `with` + explicit encoding fixes all four.
        book = cls()
        with open(path, newline="", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                book.add(Order(row["order_id"], row["customer"], float(row["amount"]), row["placed_at"]))
        return book

02 · Module 1 flash cards

Twenty-four cards. The first six are the brief's own topic list.

Click a card to open it. Say the answer out loud before you open it; the quiz is multi-select, so aim to list everything that is true, and know the distractors.

L1 vs L2 regularization — what does each do to the weights, and when do you pick which?
  • L1 (Lasso) adds λ·Σ|w|; the penalty has a constant gradient, so weights are driven exactly to zero → sparse models, built-in feature selection.
  • L2 (Ridge) adds λ·Σw²; gradient shrinks with the weight, so weights get small but non-zero → smooth shrinkage, handles correlated features better (spreads weight across them; L1 picks one arbitrarily).
  • Elastic Net = both. L2 has a closed form; L1 does not (needs coordinate descent / subgradients). Both reduce variance at the cost of bias.
Overfitting — list the causes and the fixes.
  • Symptoms: train error ≪ validation error; the gap grows with training.
  • Causes: model too complex for the data, too little data, too many epochs, noisy labels/features, leakage from the validation set, no regularization.
  • Fixes: more data / augmentation, regularization (L1/L2, dropout, weight decay), early stopping, simpler model or fewer features, cross-validation for selection, ensembling (bagging), pruning (trees).
  • Multi-select trap: “increase the learning rate” and “add more features” are not fixes.
Bayes' rule and Naive Bayes — what are the limitations?
  • P(A|B) = P(B|A)·P(A) / P(B). You need the prior P(A), which is often unknown or subjective; the result is only as good as the prior.
  • Naive Bayes assumes features are conditionally independent given the class — rarely true, so probabilities are badly calibrated even when the argmax is right.
  • Zero-frequency problem: an unseen feature value zeroes the whole product → Laplace (add-one) smoothing.
  • Continuous features need a distribution assumption (Gaussian NB). Cannot learn feature interactions.
Choosing k in kNN — what happens at small and large k, and how do you pick?
  • Small k (k=1): low bias, high variance — jagged boundary, sensitive to noise and outliers.
  • Large k: smooth boundary, high bias — majority class dominates; at k=n every prediction is the majority class.
  • Pick by cross-validation on the validation error. Heuristic √n. Use an odd k for binary classes to avoid ties. Scale features first — distance is meaningless across mismatched units.
  • kNN has no training step; prediction is O(n·d) per query.
Gradient Boosting vs Random Forest.
  • Random Forest: bagging — many deep trees trained in parallel on bootstrap samples with random feature subsets; average/vote. Reduces variance. Hard to overfit, few hyperparameters, robust to noise.
  • GBM: boosting — shallow trees trained sequentially, each fitting the residuals (negative gradient) of the ensemble so far, added with a learning rate. Reduces bias. Usually more accurate, but can overfit with too many rounds and is sensitive to noisy labels; key knobs are n_estimators, learning rate, max_depth, subsample.
  • RF trains in parallel; GBM cannot. XGBoost/LightGBM = regularized, histogram-based GBMs.
Neural network fundamentals — the forward pass, activations, and what the brief's sample asks.
  • Each neuron: z = Σ wᵢxᵢ + b, a = f(z). Layers chain: output of one is input to the next.
  • Sigmoid σ(z)=1/(1+e⁻ᶻ) ∈ (0,1); σ(0)=0.5, σ(1)≈0.731, σ(2)≈0.881, σ(−1)≈0.269, σ(0.5)≈0.622. ReLU = max(0,z). tanh ∈ (−1,1). Softmax for multi-class output. Linear = identity.
  • The brief's sample: a small diagram, linear hidden units, sigmoid output, biases 0 — compute the output to three decimals by hand. Worked example in section 03.
  • Backprop = chain rule; the learning rate scales the gradient step; vanishing gradients come from saturating activations (sigmoid/tanh) in deep stacks.
Bias–variance tradeoff — define both and name a high-bias and a high-variance model.
  • Bias: error from wrong assumptions — the model cannot represent the truth (underfitting). High-bias: linear regression on a curved relation, large-k kNN, shallow trees.
  • Variance: error from sensitivity to the particular training sample (overfitting). High-variance: deep unpruned trees, k=1 kNN, high-degree polynomials.
  • Expected error = bias² + variance + irreducible noise. Regularization and bagging trade variance for bias; boosting trades bias for variance.
Confusion matrix → accuracy, precision, recall, F1, specificity. When does accuracy mislead?
  • Accuracy = (TP+TN)/all. Precision = TP/(TP+FP) — of what I flagged, how much was right. Recall (sensitivity, TPR) = TP/(TP+FN) — of what was real, how much I caught. Specificity = TN/(TN+FP). F1 = 2PR/(P+R), the harmonic mean — punishes imbalance between P and R.
  • Accuracy misleads under class imbalance: 99% negatives → “always negative” scores 99%.
  • Raising the threshold raises precision and lowers recall. Worked numbers in section 03.
ROC-AUC vs log loss vs PR-AUC — what does each measure?
  • ROC curve: TPR vs FPR across thresholds; AUC = probability a random positive is ranked above a random negative. 0.5 = random, 1.0 = perfect. Threshold-free, insensitive to class balance — which is why it can look fine on rare-positive data.
  • PR-AUC: precision vs recall; the honest metric under heavy imbalance.
  • Log loss = −mean[y·log p + (1−y)·log(1−p)]; punishes confident wrong probabilities; measures calibration, not just ranking. A model can have high AUC and bad log loss.
Train / validation / test — what is each for, and what is data leakage?
  • Train fits parameters; validation selects hyperparameters / early-stopping point / model; test is touched once, at the end, for the reported number.
  • k-fold cross-validation: k rotations of train/validate, average the score — better use of small data, k=5 or 10. Stratified keeps class ratios per fold. Time series → forward-chaining splits, never shuffled.
  • Leakage: information from validation/test (or the future) reaches training — scaling/imputing/feature-selecting on the full data before splitting, target-derived features, duplicate rows across splits. Symptom: too-good validation, bad production.
Gradient descent — batch vs SGD vs mini-batch, and what the learning rate does.
  • w ← w − η·∇L(w). Batch: exact gradient over all data per step, slow per step, smooth. SGD: one sample per step, noisy but cheap, can escape shallow minima. Mini-batch: the practical default (32–512).
  • η too large: divergence / oscillation; too small: crawls, stuck in plateaus. Schedules and Adam (per-parameter adaptive rates + momentum) fix most of it.
  • Feature scaling matters: unscaled features make the loss surface elongated and GD zig-zags.
Linear regression vs logistic regression — loss, output, assumptions.
  • Linear: ŷ = wᵀx + b, minimizes MSE; closed form (normal equation) or GD. Assumes linearity, independent errors, homoscedasticity; sensitive to outliers and multicollinearity.
  • Logistic: p = σ(wᵀx + b), minimizes log loss (cross-entropy); no closed form. Output is a probability; decision boundary is linear in x. Coefficients are log-odds.
  • Regression metrics: MSE, RMSE (same units as y), MAE (robust to outliers), R² = 1 − SS_res/SS_tot.
Decision trees — how a split is chosen, and why they overfit.
  • Greedy: at each node pick the (feature, threshold) that most reduces impurity — Gini = 1 − Σpᵢ², entropy = −Σpᵢ·log₂pᵢ, information gain = parent − weighted children. Regression trees use variance / MSE.
  • Grown to purity they memorize noise → control with max_depth, min_samples_leaf, pruning, or ensembling.
  • No scaling needed; handles mixed types; axis-aligned boundaries; unstable (small data change → different tree), which is exactly what bagging exploits.
Bagging vs boosting vs stacking.
  • Bagging: bootstrap samples → independent models → average/vote. Cuts variance. Random Forest = bagging + random feature subsets.
  • Boosting: sequential weak learners, each correcting the last (AdaBoost reweights samples; gradient boosting fits residuals). Cuts bias; more overfit-prone.
  • Stacking: heterogeneous models whose predictions feed a meta-learner, trained on out-of-fold predictions to avoid leakage.
k-Means — algorithm, how to pick k, failure modes.
  • Init k centroids → assign each point to nearest → recompute centroids as means → repeat until assignments stop changing. Minimizes within-cluster sum of squares. Converges to a local optimum → run several inits (k-means++ picks spread-out starts).
  • Pick k with the elbow (inertia vs k) or silhouette score.
  • Assumes spherical, similar-size clusters; sensitive to scale and outliers; needs k up front. GMM is the soft, elliptical generalization; DBSCAN finds arbitrary shapes without k.
Gaussian Mixture Models and EM — what are the two steps?
  • Data modeled as a weighted sum of k Gaussians (πⱼ, μⱼ, Σⱼ). E-step: responsibilities rᵢⱼ = πⱼ·N(xᵢ|μⱼ,Σⱼ) / Σₖ πₖ·N(xᵢ|μₖ,Σₖ). M-step: πⱼ = mean of rᵢⱼ; μⱼ = weighted mean; Σⱼ = weighted covariance. Repeat until log-likelihood stops improving.
  • Soft assignments (vs k-Means hard); each iteration is guaranteed not to decrease the likelihood; local optima and singular covariances (a component collapsing onto one point) are the failure modes.
Class imbalance — what do you do?
  • Metrics first: precision/recall/F1/PR-AUC, never plain accuracy.
  • Resampling: oversample minority (SMOTE synthesizes), undersample majority. Class weights in the loss. Threshold tuning on the validation set. Anomaly-detection framing when positives are extremely rare.
  • Resample only the training fold, never the validation data.
Feature scaling and encoding — which models need it, and which encodings exist?
  • Need scaling: anything distance- or gradient-based — kNN, k-Means, SVM, logistic/linear regression with regularization, neural nets, PCA. Don't: trees and tree ensembles.
  • Min-max → [0,1]; z-score → mean 0, std 1 (use for Gaussian-ish, outlier-sensitive); robust scaling uses median/IQR.
  • Categorical: one-hot (nominal), ordinal codes (ordered), target encoding (high cardinality — leak-prone, do it out-of-fold). Fit the scaler on train only.
PCA — what it does and what it assumes.
  • Finds orthogonal directions of maximum variance (eigenvectors of the covariance matrix); project onto the top m to reduce dimension. Explained-variance ratio tells you how many to keep.
  • Standardize first or the largest-scale feature dominates. Linear, unsupervised, loses interpretability; captures variance, not necessarily class separation (LDA does that).
Dropout, batch norm, early stopping — what does each do?
  • Dropout: randomly zero a fraction of activations during training; an implicit ensemble; turned off (scaled) at inference. Regularizes.
  • Batch norm: normalizes each layer's inputs per mini-batch; stabilizes and speeds training, allows larger learning rates, mild regularization.
  • Early stopping: stop when validation loss stops improving; the cheapest regularizer.
Precision vs recall — which do you optimize for fraud detection, spam, cancer screening?
  • Ask what each error costs. Cancer screening / fraud triage: a miss is expensive → maximize recall, accept false positives that a second stage filters.
  • Spam / auto-blocking a customer: a false positive is expensive → maximize precision.
  • Move the threshold, don't retrain: lower threshold → recall ↑ precision ↓.
Train accuracy high, validation low — what's wrong and what are the fixes? (the classic multi-select)
  • Diagnosis: overfitting (high variance). Also check for a distribution shift between train and validation, and for leakage into train that the validation set lacks.
  • Correct answers on a multi-select: more training data · regularization · early stopping · reduce model complexity / features · dropout · cross-validation · ensembling (bagging).
  • Wrong distractors: raise learning rate · add layers · train longer · remove regularization.
Curse of dimensionality — why does it hurt kNN, and what helps?
  • In high dimensions all pairwise distances concentrate toward the same value, so “nearest” loses meaning; data becomes sparse; the volume needed for a fixed density grows exponentially.
  • Helps: feature selection, PCA/embeddings, regularization, distance metrics that ignore irrelevant dimensions, more data.
Parametric vs non-parametric; supervised vs unsupervised — quick classification of the usual models.
  • Parametric (fixed number of parameters): linear/logistic regression, Naive Bayes, neural nets. Non-parametric (grows with data): kNN, decision trees, kernel SVM, GMM with unknown k.
  • Supervised: regression, classification. Unsupervised: k-Means, GMM, PCA, DBSCAN. Semi-/self-supervised and RL are the other two families a multi-select might list.

The brief's sample Neural network

Forward pass to three decimals

Inputs x = (1.0, 2.0). Hidden layer, two linear neurons, biases 0: h₁ has weights (0.5, −0.2), h₂ has weights (0.1, 0.4). Output neuron, sigmoid, weights (0.3, 0.7) on (h₁, h₂). What is the output?

  • h₁ = 0.5·1.0 + (−0.2)·2.0 = 0.5 − 0.4 = 0.1
  • h₂ = 0.1·1.0 + 0.4·2.0 = 0.1 + 0.8 = 0.9
  • z = 0.3·0.1 + 0.7·0.9 = 0.03 + 0.63 = 0.66
  • σ(0.66) = 1 / (1 + e⁻⁰·⁶⁶) = 1 / (1 + 0.5169) = 0.659

The forward skeleton in section 05 reproduces exactly this and asserts 0.659. Memorize e⁻¹ ≈ 0.368, e⁻⁰·⁵ ≈ 0.607, e⁻² ≈ 0.135; interpolate the rest or use the calculator.

Worked Metrics

Confusion matrix → the five numbers

100 samples, 20 positive. Model predicts 25 positive, of which 15 are truly positive.

  • TP = 15 · FP = 10 · FN = 5 · TN = 70
  • Precision = 15/25 = 0.60 · Recall = 15/20 = 0.75
  • F1 = 2·0.6·0.75 / 1.35 = 0.667 · Accuracy = 85/100 = 0.85 · Specificity = 70/80 = 0.875
  • “Always negative” would score accuracy 0.80 — that is the imbalance point the quiz wants you to make.

Worked Bayes

The disease-test question

Prevalence 1%. Test sensitivity 90%, specificity 95%. Positive result — probability of disease?

  • P(+|D) = 0.90, P(+|¬D) = 0.05, P(D) = 0.01
  • P(+) = 0.90·0.01 + 0.05·0.99 = 0.009 + 0.0495 = 0.0585
  • P(D|+) = 0.009 / 0.0585 = 0.154
  • The “limitation” framing: the answer is dominated by the prior; with a 10% prior it becomes 0.667.

Worked Impurity

Gini and entropy of a node

Node with 6 positives, 2 negatives.

  • p = 0.75, q = 0.25. Gini = 1 − (0.5625 + 0.0625) = 0.375
  • Entropy = −(0.75·log₂0.75 + 0.25·log₂0.25) = −(0.75·(−0.415) + 0.25·(−2)) = 0.311 + 0.5 = 0.811 bits
  • Split into (6,0) and (0,2): both children pure, weighted impurity 0, information gain = 0.811.

    count = 0
    for word in sentence.split():
        w = word.lower()
        if any(w.count(ch) >= 3 for ch in set(w)):

    return count

def digit_balance(n):
    even = odd = 0
    for ch in str(abs(n)):
        d = int(ch)
        if d % 2 == 0:
            even += d
        else:
            odd += d
    return even - odd

    out = []

# Variation: count pairs of words (i < j) that are anagrams of each other, case-insensitive.
# anagram_pairs("Listen silent enlist tinsel banana") -> 6  (4 anagrams -> C(4,2))
def anagram_pairs(sentence):
    keys = ["".join(sorted(w.lower())) for w in sentence.split()]
    pairs = 0
    for i in range(len(keys)):
        for j in range(i + 1, len(keys)):
            if keys[i] == keys[j]:
                pairs += 1
    return pairs

# Module 3 sample (verbatim shape from the brief). Only euc_dist and k_neighbors are yours.
def euc_dist(value1, value2):
    return sum((a - b) ** 2 for a, b in zip(value1, value2)) ** 0.5

def k_neighbors(train_data, test_case, k):
    scored = [(euc_dist(row[:-1], test_case), row) for row in train_data]
    scored.sort(key=lambda pair: pair[0])
    return [row for _, row in scored[:k]]

def get_label(train_data, test_case, k):
    neighbors = k_neighbors(train_data, test_case, k)
    labels = [row[-1] for row in neighbors]
    max_label = max(set(labels), key=labels.count)
    return max_label

def knn_solution(train_data, test_data, k):
    final_labels = list()
    for row in test_data:
        label = get_label(train_data, row, k)
        final_labels.append(label)
    return final_labels

# k-Means: assign each point to its nearest centroid, recompute centroids as the
# coordinate-wise mean, stop when nothing moves. An empty cluster keeps its old centroid.
def assign_clusters(points, centroids):
    labels = []
    for p in points:
        dists = [euc_dist(p, c) for c in centroids]
        labels.append(dists.index(min(dists)))
    return labels

def update_centroids(points, labels, old_centroids):
    new_centroids = []
    for j, old in enumerate(old_centroids):
        members = [p for p, lab in zip(points, labels) if lab == j]
        if not members:
            new_centroids.append(list(old))
            continue
        dim = len(members[0])
        new_centroids.append([sum(m[d] for m in members) / len(members) for d in range(dim)])
    return new_centroids

    labels = assign_clusters(points, centroids)
    for _ in range(max_iter):
        new_centroids = update_centroids(points, labels, centroids)
        new_labels = assign_clusters(points, new_centroids)
        centroids = new_centroids
        if new_labels == labels:

def minmax_normalize(matrix):
    cols = list(zip(*matrix))
    lows = [min(c) for c in cols]
    highs = [max(c) for c in cols]
    out = []
    for row in matrix:
        out.append([(v - lo) / (hi - lo) if hi != lo else 0.0
                    for v, lo, hi in zip(row, lows, highs)])
    return out

def zscore_normalize(matrix):
    cols = list(zip(*matrix))
    means = [sum(c) / len(c) for c in cols]
    stds = [(sum((v - m) ** 2 for v in c) / len(c)) ** 0.5 for c, m in zip(cols, means)]
    return [[(v - m) / s if s else 0.0 for v, m, s in zip(row, means, stds)] for row in matrix]

    out = []
    for row in matrix:
        norm = sum(v * v for v in row) ** 0.5
        out.append([v / norm if norm else 0.0 for v in row])

# Decision-tree pieces: impurity, a threshold split, and the best (feature, threshold)
# by weighted Gini. rows carry features first and the class label LAST.
def gini(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    return 1.0 - sum((labels.count(c) / n) ** 2 for c in set(labels))

def entropy(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    total = 0.0
    for c in set(labels):
        p = labels.count(c) / n
        total -= p * math.log2(p)
    return total

def split_rows(rows, feature, threshold):
    left = [r for r in rows if r[feature] <= threshold]
    right = [r for r in rows if r[feature] > threshold]
    return left, right

def best_split(rows):
    best_feature, best_threshold, best_score = None, None, float("inf")
    n = len(rows)
    for feature in range(len(rows[0]) - 1):
        for threshold in sorted(set(r[feature] for r in rows)):
            left, right = split_rows(rows, feature, threshold)
            if not left or not right:
                continue
            score = (len(left) / n) * gini([r[-1] for r in left]) \
                  + (len(right) / n) * gini([r[-1] for r in right])
            if score < best_score:
                best_feature, best_threshold, best_score = feature, threshold, score
    return best_feature, best_threshold, best_score

def bagging_predict(train_data, test_data, n_models, fit, predict, seed=0):
    rng = random.Random(seed)
    models = [fit(bootstrap_sample(train_data, rng)) for _ in range(n_models)]
    results = []
    for row in test_data:
        votes = [predict(model, row) for model in models]
        results.append(majority_vote(votes))
    return results

# 1-D Gaussian mixture by EM. E-step: responsibilities. M-step: weighted mean/variance/weight.
def gaussian_pdf(x, mean, var):
    return math.exp(-((x - mean) ** 2) / (2.0 * var)) / math.sqrt(2.0 * math.pi * var)

def e_step(xs, weights, means, variances):
    resp = []
    for x in xs:
        numer = [w * gaussian_pdf(x, m, v) for w, m, v in zip(weights, means, variances)]
        total = sum(numer)
        resp.append([n / total for n in numer])
    return resp

def m_step(xs, resp):
    k = len(resp[0])
    n = len(xs)
    weights, means, variances = [], [], []
    for j in range(k):
        r_j = [r[j] for r in resp]
        n_j = sum(r_j)
        mean = sum(r * x for r, x in zip(r_j, xs)) / n_j
        var = sum(r * (x - mean) ** 2 for r, x in zip(r_j, xs)) / n_j
        weights.append(n_j / n)
        means.append(mean)
        variances.append(max(var, 1e-6))
    return weights, means, variances

def gmm_1d(xs, init_means, iters=50):
    k = len(init_means)
    weights = [1.0 / k] * k
    means = list(init_means)
    variances = [1.0] * k
    for _ in range(iters):
        resp = e_step(xs, weights, means, variances)
        weights, means, variances = m_step(xs, resp)
    return weights, means, variances

def manhattan_dist(a, b):
    return sum(abs(x - y) for x, y in zip(a, b))

def cosine_similarity(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    na = sum(x * x for x in a) ** 0.5
    nb = sum(y * y for y in b) ** 0.5
    return dot / (na * nb) if na and nb else 0.0

def softmax(zs):
    m = max(zs)
    exps = [math.exp(z - m) for z in zs]
    s = sum(exps)
    return [e / s for e in exps]

def linear_regression_gd(xs, ys, lr=0.01, epochs=1000):
    # y = w * x + b, batch gradient descent on MSE
    w = b = 0.0
    n = len(xs)
    for _ in range(epochs):
        preds = [w * x + b for x in xs]
        dw = (2.0 / n) * sum((p - y) * x for p, y, x in zip(preds, ys, xs))
        db = (2.0 / n) * sum(p - y for p, y in zip(preds, ys))
        w -= lr * dw
        b -= lr * db
    return w, b

def logistic_step(weights, bias, xs, ys, lr):
    # one batch gradient-descent step on log loss; xs is a list of feature rows
    n = len(xs)
    grads = [0.0] * len(weights)
    grad_b = 0.0
    for row, y in zip(xs, ys):
        p = sigmoid(sum(w * x for w, x in zip(weights, row)) + bias)
        err = p - y
        for i, x in enumerate(row):
            grads[i] += err * x / n
        grad_b += err / n
    return [w - lr * g for w, g in zip(weights, grads)], bias - lr * grad_b

def precision_recall_f1(y_true, y_pred, positive=1):
    tp = sum(1 for t, p in zip(y_true, y_pred) if t == positive and p == positive)
    fp = sum(1 for t, p in zip(y_true, y_pred) if t != positive and p == positive)
    fn = sum(1 for t, p in zip(y_true, y_pred) if t == positive and p != positive)
    precision = tp / (tp + fp) if tp + fp else 0.0
    recall = tp / (tp + fn) if tp + fn else 0.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
    return precision, recall, f1

The IDE and the run

  • Run the provided examples before submitting. Hidden tests exist; passing the visible ones is not a pass.
  • Return floats when the example shows floats (1.0, not 1); match the list/tuple type the skeleton's caller expects.
  • No import numpy; import math and import random are fine unless the task says “no imports at all” — the kNN sample says exactly that, so use ** 0.5 for square roots.

The quiz

  • Read every option. A multi-select is scored on the whole selection; one wrong tick can zero the question.
  • “Which of the following would help with overfitting” — answer from the card, do not reason from scratch under the clock.
  • Numeric fill-ins: round as instructed (the sample says three decimals). Compute on paper, then type.
  • You cannot go back after submitting a module in most configurations; do not leave a quiz blank — a guess scores better than nothing.

Ties and determinism

The given get_label uses max(set(labels), key=labels.count), which breaks ties by set iteration order — arbitrary. The brief's example has no ties, but your k_neighbors must return rows in ascending distance order so the k chosen are the right k. Sort with key=lambda pair: pair[0]; do not sort tuples that contain the rows themselves, because a tie on distance would then compare lists element-wise and can still work but hides the intent.

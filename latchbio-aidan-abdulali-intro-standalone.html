1 · The benchmark factory

Thousands of sandboxed runs every time a model ships

Every new model is run across a dozen benchmarks and several harnesses. Each run is a sandbox with the data snapshot mounted and no internet. 07 · What he'll probably ask

Likely questions, with answer sketches

Keep each answer to about a minute, then offer to go deeper. In a 30-minute intro, one design question at most is likely. The real technical depth comes in rounds 2 and 3.

“Tell me about the hardest infrastructure problem you've worked on.”

Tell one story with numbers: getting about 100 agents to share one working tree. They clobbered each other's edits, killed each other's processes and broke the release gate.

  • Locks: enforced by a hook before every edit, not advisory, because agents ignore advisory rules.
  • Commits: a background sync commits the whole tree on a schedule and hands merge conflicts to a resolver agent, so no agent runs git itself.
  • Processes: a ledger where every long-lived process lives in its own cgroup. Kills take out the whole subtree, and pressure can be relieved by freezing instead of killing.

The lesson: make the safe path the only path.

“How would you run tens of thousands of agent evals whenever a new model ships?”
  • Pin everything. An eval is a data snapshot hash, prompt, grader and container image digest. A run is model × harness × eval × seed, with model and harness versions recorded.
  • Queue. Postgres with SKIP LOCKED, or Kubernetes Jobs, with per-provider concurrency and budget limits so 429s don't flood the queue.
  • Sandbox per run. Container or microVM, CPU, memory and time limits, no internet, data read-only, a writable scratch space.
  • Grade outside the sandbox, so the agent can't touch the grader. Save the full trajectory, tokens, cost, time and exit reason.
  • Keep infra failures out of the score. OOMs, provider errors and sandbox crashes get retried. Wrong answers don't. Otherwise the leaderboard is measuring your infrastructure.
  • Report with confidence intervals, and keep the full eval set private so it can't leak into training data. SpatialBench already holds its full set back.
“How do you sandbox an agent that runs arbitrary code but can't reach the internet?”

Run the harness inside a container or microVM (gVisor or Firecracker if you don't trust the code). Give it a network namespace that blocks all outbound traffic by default. The only way out is a proxy that allows just the model API host and adds the API key itself, so the key never sits inside the sandbox. Use a read-only base image, read-only data, a scratch overlay, cgroup limits and a hard timeout that kills the whole process tree. Log every command.

The model API is the one hole left open. For biosecurity work, that makes logging prompts and responses a feature, not overhead.

“An agent needs a 3 TB spatial dataset. How do you get it there?”

Don't copy it for every run. Cache it by content hash on node-local NVMe and share it read-only across runs on the same machine. Send runs to nodes that already have the data. Read lazily in chunks, the way his Latch Data FUSE mount does, so an agent that only opens metadata never pulls terabytes. Pre-subset the data where the task allows.

But you've read scBench and SpatialBench and know how the pipeline fits together: sequencing reads → a cells × genes count matrix (AnnData / .h5ad) → Scanpy or Seurat → QC, normalization, clustering, cell typing, differential expression. You learn a domain by building in it, which is how you learned commerce and warehouse operations. See the glossary below.

09 · Vocabulary

Biology words you might hear

Enough to follow along, not to fake expertise.

Data
  • NGS / FASTQ: next-generation sequencing. FASTQ files hold the raw reads.
  • scRNA-seq: gene activity measured cell by cell. The result is a cells × genes matrix, usually an AnnData .h5ad file.
  • Spatial transcriptomics: the same measurement, but each spot or cell has a position in the tissue. Platforms include 10x Xenium and Visium, Vizgen MERSCOPE, Curio and AtlasXomics. One run can be terabytes.
  • Nextflow: a common bioinformatics workflow language. Latch integrates with it.
Analysis steps
  • QC → normalization → dimensionality reduction (PCA/UMAP) → clustering → cell typing → differential expression. These are basically SpatialBench's task categories, plus spatial analysis.
  • Scanpy (Python) and Seurat (R): the standard toolkits.
  • Variant calling: finding where a genome differs from a reference.
  • Epigenomics: chemical marks that switch genes on and off (e.g. ATAC-seq, methylation).
Their benchmark areas
  • ASO / siRNA: short synthetic RNA-like drugs that silence one gene (oligonucleotide therapeutics).
  • Antibody discovery, preclinical pharmacology: the other two TxBench sets.
  • Metagenomics: sequencing every microbe in a sample, such as a gut microbiome.
  • Biosecurity refusal: whether a model declines to help with dangerous biology while still doing useful work.
